# Conclusão do serviço — Ferreira Motores

[Baixar ou visualizar o PDF preenchível](Ferreira-Motores-Conclusao-de-Servico.pdf).

Modelo de uma página para enviar ao cliente quando o serviço estiver concluído.
Usa o logo original e as cores da Ferreira Motores, com campos para cliente,
ordem de serviço, equipamento, trabalho realizado, orientações, valores e
retirada ou entrega. O botão de WhatsApp abre o número (31) 99423-1451.

## Como usar

1. Abra em um leitor de PDF com suporte a formulários, como Adobe Acrobat Reader.
2. Preencha os dados do atendimento e registre somente o que foi executado e combinado.
3. Confira valor do serviço, valor pago e saldo. Os valores não são calculados automaticamente.
4. Selecione retirada ou entrega e informe o horário quando estiver combinado.
5. Salve uma cópia por atendimento e confira antes de enviar ao cliente.

O arquivo armazenado neste repositório é o modelo em branco, com 12 campos
preenchíveis. Guarde cópias com dados de clientes fora do repositório.
O PDF não faz parte do pacote de publicação do site na Hostinger.
